cross-platform desktop tracing/profiling tool

Usage: sismo [COMMAND]

Commands:
  record      Spawn a command (or attach to --pid) and record sched + CPU samples + heap into a single Perfetto trace. Stops on SIGINT, target exit, or --duration. Requires sudo on macOS for kdebug + task_for_pid
  prepare     Launch a command with sismo's dormant heap client preloaded, so it can be attached to later via `sismo record --pid <pid>`
  snapshot    Snapshot a running flight-recorder session (`sismo record --flight-recorder`): clone it as a fresh consumer and write the trace
  datasource  Run a daemonized data-source producer for an external `sismo record`
  help        Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
